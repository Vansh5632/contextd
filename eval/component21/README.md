# Component 2.1 evaluation

This package scores the current `contextd` daemon against an explicit memory contract. It does not replace the extractor, and a failing case is a measurement.

Start with [docs/architecture.md](docs/architecture.md). The corrected rates are [docs/integrity-report.md](docs/integrity-report.md). The 17 November capture is [docs/baseline-report.md](docs/baseline-report.md). The coverage of the twenty failure categories is [docs/failure-coverage.md](docs/failure-coverage.md). Deterministic reason codes and the inert shadow verifier are in [docs/shadow-diagnostics.md](docs/shadow-diagnostics.md).
